Novos conceitos

ConceitoFunção
Injeção de dependênciaTeste entrega store temporário ao servidor.
FábricacreateServer(store) cria servidor, sem iniciar porta.
Banco temporárioSQLite criado e removido no fim do teste.
AssertionVerificação de status e JSON.
Porta aleatórialisten(0) evita conflito com 3000.

Fluxo

npm test
  → test/server.test.js
  → createTaskStore(caminho temporário)
  → createServer(store)
  → server.listen(0)
  → fetch HTTP + assertions
  → fecha servidor + apaga temporários

package.jsonnpm test executa node --test.

PowerShell

curl é alias de Invoke-WebRequest. Em validação manual, use Invoke-WebRequest -UseBasicParsing; 4xx aparecem como exceção, mas confirmam status esperado.
