# Recursos do FocoAI

## Knowledge

- [Git: documentação de branches](https://git-scm.com/docs/git-branch)
  Referência oficial para criar, listar, renomear e remover branches. Use ao separar uma funcionalidade do trabalho principal.
- [Git: documentação de rebase](https://git-scm.com/docs/git-rebase)
  Referência oficial para reaplicar commits sobre outra base e resolver conflitos. Use antes de reescrever histórico local.
- [VS Code: Git, branches e worktrees](https://code.visualstudio.com/docs/sourcecontrol/branches-worktrees)
  Guia oficial para visualizar mudanças, criar branches e usar worktrees pelo editor. Use ao executar os exercícios de Git no VS Code.
- [SQLite: Quick Start](https://www.sqlite.org/quickstart.html)
  Introdução oficial ao banco de dados em arquivo e ao uso de SQL. Use para criar e inspecionar o banco local.
- [OpenAI: Developer quickstart](https://platform.openai.com/docs/quickstart)
  Guia oficial para configurar uma chave por variável de ambiente e fazer uma primeira chamada de API. Use apenas na aula de integração de IA.

## Wisdom (Communities)

- [GitHub Community](https://github.com/orgs/community/discussions)
  Fórum oficial para dúvidas práticas de GitHub, pull requests e colaboração.
- [Stack Overflow — tag git](https://stackoverflow.com/questions/tagged/git)
  Banco de casos reais para comparar mensagens de erro e estratégias de recuperação. Pesquise antes de perguntar e inclua um exemplo reproduzível.

## Gaps

- A publicação do FocoAI será escolhida quando a aplicação local estiver funcional; a opção dependerá do tipo de deploy que o usuário quiser praticar.
