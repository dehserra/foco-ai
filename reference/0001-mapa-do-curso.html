FocoAI: do zero ao ciclo completo

Aplicação web local que registra tarefas em SQLite e usa IA para propor próximos passos. Cada aula termina com uma evidência: comando, teste, pull request ou tela funcional.

Definição de pronto: um repositório no GitHub contém uma aplicação demonstrável, histórico compreensível, testes básicos e instruções para executar localmente.

Regras de segurança do Git

  1. Antes de qualquer alteração: git status.
  2. Antes de rebase: confirme se os commits já foram publicados e se outra pessoa depende deles.
  3. Antes de remover um worktree: confirme que não há mudanças não salvas.
  4. Nunca faça commit de .env ou de uma chave da API.
