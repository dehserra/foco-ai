Comandos

ComandoUso
npm run devInicia aplicação local na porta 3000.
npm testExecuta testes descobertos pelo node --test.
node --test test/server.test.jsExecuta somente teste da API.

Separação essencial

Aplicação: createServer() usa data/foco-ai.db
Teste:     createServer(storeTemporario) usa banco temporário
TrechoIdeia
createTaskStore(path)Escolhe onde SQLite será criado.
createServer(store)Entrega dependência ao servidor.
server.listen(0)Usa porta livre, não 3000.
assert.equal(valor, esperado)Falha se valor divergir.
t.after(...)Fecha servidor e remove arquivos temporários.

Contrato mínimo da API

PedidoEsperado
GET /tasks200 e lista
POST /tasks201 e tarefa pendente
PATCH /tasks/:id200 e tarefa atualizada
POST sem título400
PATCH id inexistente404
POST duplicado409

Diagnóstico rápido

createServer is not a function: confira module.exports = { createServer }.

dirname is not defined: importe dirname de node:path.

porta já em uso: teste deve chamar listen(0); pare npm run dev antes de depurar.

teste altera tarefas reais: confira se o teste passa caminho temporário para createTaskStore.
