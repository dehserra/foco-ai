API de tarefas: valide e automatize

Você já validou API no PowerShell. Agora vai transformar essa prova manual em npm test, com SQLite e porta temporários.

Vitória: npm test termina verde e não altera data/foco-ai.db.

Mapa conceitual · Referência rápida

Checkpoint concluído

Você já confirmou no PowerShell: GET 200, POST 201, PATCH 200, título ausente 400, id inexistente 404 e título duplicado 409. Não repita esses pedidos agora.

Mapa

teste → SQLite temporário → createTaskStore(caminho)
      → createServer(store) → porta temporária → HTTP + assertions

Fora de escopo: interface, autenticação, deploy e IA.

1. Confira mudanças

  1. No VS Code, abra Source Control (Ctrl+Shift+G). Veja mudanças em src/. Não use git add -A.
  2. No terminal da raiz, execute:
    git status
node --version
    Esperado: Node 24+ e alterações intencionais.

2. Faça banco respeitar caminho temporário

Em src/database.js, importe dirname:

const { dirname, join } = require("node:path");

Dentro de createTaskStore, use:

mkdirSync(dirname(databasePath), { recursive: true });

Isso cria a pasta do banco entregue pelo teste, não sempre data/.

3. Faça servidor ser testável

Em src/server.js, transforme criação atual em fábrica: envolva atual http.createServer(...) em function createServer(store = createTaskStore()), usando store.listTasks(), store.createTask(...) e store.updateTaskStatus(...). No fim, substitua início incondicional por:

if (require.main === module) {
  const server = createServer();
  const PORT = process.env.PORT || 3000;
  server.listen(PORT, () => {
    console.log(`FocoAI disponível em http://localhost:${PORT}`);
  });
}

module.exports = { createServer };

Por quê: teste importa arquivo sem abrir porta 3000; aplicação continua iniciando com npm run dev.

4. Crie teste

  1. No Explorer, raiz → New Folder → test.
  2. Crie test/server.test.js.
  3. Cole:
const assert = require("node:assert/strict");
const { mkdtempSync, rmSync } = require("node:fs");
const { tmpdir } = require("node:os");
const { join } = require("node:path");
const test = require("node:test");
const { createTaskStore } = require("../src/database");
const { createServer } = require("../src/server");

async function request(server, path, options = {}) {
  const { port } = server.address();
  const response = await fetch(`http://127.0.0.1:${port}${path}`, options);
  return { status: response.status, body: await response.json() };
}

test("API cria, lista e conclui tarefas", async (t) => {
  const directory = mkdtempSync(join(tmpdir(), "foco-ai-test-"));
  const store = createTaskStore(join(directory, "foco-ai-test.db"));
  const server = createServer(store);
  await new Promise((resolve) => server.listen(0, "127.0.0.1", resolve));
  t.after(async () => {
    await new Promise((resolve) => server.close(resolve));
    store.close();
    rmSync(directory, { recursive: true, force: true });
  });
  const initial = await request(server, "/tasks");
  assert.equal(initial.status, 200);
  assert.deepEqual(initial.body, { tasks: [] });
  const created = await request(server, "/tasks", { method: "POST", headers: { "Content-Type": "application/json" }, body: JSON.stringify({ title: "Testar API automaticamente" }) });
  assert.equal(created.status, 201);
  const updated = await request(server, `/tasks/${created.body.task.id}`, { method: "PATCH", headers: { "Content-Type": "application/json" }, body: JSON.stringify({ status: "done" }) });
  assert.equal(updated.status, 200);
  assert.equal(updated.body.task.status, "done");
  const missingTitle = await request(server, "/tasks", { method: "POST", headers: { "Content-Type": "application/json" }, body: JSON.stringify({}) });
  assert.equal(missingTitle.status, 400);
  const missingTask = await request(server, "/tasks/9999", { method: "PATCH", headers: { "Content-Type": "application/json" }, body: JSON.stringify({ status: "done" }) });
  assert.equal(missingTask.status, 404);
  const duplicate = await request(server, "/tasks", { method: "POST", headers: { "Content-Type": "application/json" }, body: JSON.stringify({ title: "Testar API automaticamente" }) });
  assert.equal(duplicate.status, 409);
});

5. Ligue npm test

Em package.json, mude somente:

"test": "node --test"

6. Prove

  1. Pare npm run dev com Ctrl+C, se ativo.
  2. Rode:
    npm test
    Esperado: ok 1 - API cria, lista e conclui tarefas e nenhuma falha.
  3. createServer is not a function → confira exportação final. dirname is not defined → confira importação do banco.
