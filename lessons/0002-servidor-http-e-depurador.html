Crie e depure o primeiro endpoint

Você criará um servidor Node que responde em /health. O objetivo não é uma aplicação completa: é entender o ciclo editar → executar → testar → depurar → registrar.

Vitória desta aula: http://localhost:3000/health responderá {"status":"ok"}, e o depurador do VS Code parará em um breakpoint.

Modelo mental mínimo

TermoSignificado neste projeto
Servidor HTTPPrograma que fica aguardando requisições em uma porta.
EndpointUm endereço e método, por exemplo GET /health.
Porta 3000Canal local usado para acessar este servidor no navegador.
BreakpointPausa proposital para inspecionar o código enquanto ele executa.

Faça agora

  1. Confirme que está na pasta e que o Git está limpo. No VS Code, veja se a janela mostra minicurso-dev. Clique em Terminal → Novo Terminal e execute:
    git status
node --version
    Resultado esperado: nothing to commit, working tree clean e v24.21.0 (ou outra versão 24 ou mais recente). Essa versão do Node é compatível com os comandos desta aula. Se o status listar apenas atualizações já revisadas dos materiais do curso, agrupe-as em um commit de documentação antes de iniciar esta aula: git add -A, git status, git commit -m "docs: atualizar materiais da aula" e git push. Se houver algum arquivo que você não reconhece, não use git add -A; envie aqui a saída completa.
  2. Crie o projeto Node. No mesmo terminal, execute:
    npm init -y
npm pkg set scripts.dev="node --watch src/server.js"
npm pkg set scripts.start="node src/server.js"
    npm init -y cria package.json sem perguntas; pkg set adiciona atalhos. dev reiniciará o servidor ao salvar arquivos. Confira com:
    Get-Content package.json
    Resultado esperado: uma seção scripts contendo dev e start.
  3. Crie a pasta e o arquivo do servidor pelo Explorer. Na barra lateral esquerda, clique no primeiro ícone, Explorer. Clique com o botão direito sobre a pasta raiz minicurso-dev → New Folder → escreva src → pressione Enter. Clique com o botão direito em src → New File → escreva server.js → pressione Enter.
  4. Cole o servidor. Com src/server.js aberto, substitua qualquer conteúdo por:
    const http = require("node:http");

const PORT = process.env.PORT || 3000;

const server = http.createServer((request, response) => {
  if (request.method === "GET" && request.url === "/health") {
    response.writeHead(200, { "Content-Type": "application/json" });
    response.end(JSON.stringify({ status: "ok" }));
    return;
  }

  response.writeHead(404, { "Content-Type": "application/json" });
  response.end(JSON.stringify({ error: "Rota não encontrada" }));
});

server.listen(PORT, () => {
  console.log(`FocoAI disponível em http://localhost:${PORT}`);
});
    Pressione Ctrl+S. require("node:http") usa o módulo HTTP incluído no Node; não há dependência para instalar.
  5. Execute e teste. No terminal, execute:
    npm run dev
    Resultado esperado: FocoAI disponível em http://localhost:3000. Mantenha esse terminal aberto. Abra uma nova aba no navegador e acesse http://localhost:3000/health. Você deve ver:
    {"status":"ok"}
    Para testar pelo PowerShell, em um segundo terminal do VS Code, execute:
    Invoke-RestMethod http://localhost:3000/health
    Resultado esperado: status com valor ok.
  6. Configure o depurador. No Explorer, clique com o botão direito na pasta raiz → New Folder → escreva .vscode. Dentro dela, crie launch.json e cole:
    {
  "version": "0.2.0",
  "configurations": [
    {
      "type": "node",
      "request": "launch",
      "name": "Depurar FocoAI",
      "skipFiles": ["<node_internals>/**"],
      "program": "${workspaceFolder}/src/server.js",
      "env": { "PORT": "3000" }
    }
  ]
}
    Salve com Ctrl+S. Esse arquivo diz ao VS Code qual programa Node executar ao depurar.
  7. Pause o programa de propósito. Clique na margem à esquerda da linha response.writeHead(200, ...); aparecerá um círculo vermelho. Na barra esquerda, clique em Run and Debug (ícone de triângulo com inseto), escolha Depurar FocoAI e clique no botão verde ou pressione F5. Depois abra http://localhost:3000/health novamente. O VS Code deve pausar na linha marcada. Veja no painel Variables que request.url vale /health. Pressione F5 outra vez para continuar a resposta.
  8. Encerre, revise e registre. Pare o depurador com Shift+F5. No terminal que executa npm run dev, pressione Ctrl+C. Então execute:
    git status
git add package.json src/server.js .vscode/launch.json
git commit -m "feat: adicionar servidor HTTP inicial"
git status
    Resultado esperado final: nothing to commit, working tree clean.

Se algo der errado

EADDRINUSE: a porta 3000 já está em uso. Pare o terminal anterior com Ctrl+C e execute npm run dev de novo.

Cannot find module: confirme que o arquivo está exatamente em src/server.js, salve-o e rode npm run dev novamente.

O navegador não abre: confirme que o terminal ainda mostra o servidor em execução e que a URL é http, não https.

Checagem de recuperação

Por que há dois scripts, dev e start?

dev usa --watch para reiniciar durante o desenvolvimento. start executa uma vez, sem observar alterações.

Por que a resposta de rota inexistente usa 404?

O código HTTP 404 indica que o servidor recebeu a requisição, mas não encontrou a rota solicitada.

O breakpoint muda o código publicado?

Não. Ele é uma configuração do editor para pausar a execução local e não altera server.js.
