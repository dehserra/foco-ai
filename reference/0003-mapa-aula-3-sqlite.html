SQLite: de servidor a tarefas persistentes

Leia este mapa antes da Aula 3. Ele mostra o objetivo, os conceitos, os arquivos envolvidos e o que ainda não faz parte desta etapa.

Objetivo

O FocoAI já responde GET /health, mas ainda não guarda informações. Nesta aula, ele passa a armazenar tarefas em um banco SQLite local.

Conceitos

ConceitoSignificado
ServidorPrograma que aguarda pedidos, como src/server.js.
Banco de dadosArmazenamento estruturado de dados que o programa precisa lembrar.
SQLiteBanco que vive em um arquivo local; não exige outro servidor.
TabelaColeção de registros do mesmo tipo; criaremos tasks.
SchemaDefinição das colunas e regras da tabela.
SQLLinguagem para criar, inserir e consultar dados.

Mapa das peças

Navegador
   ↓ pede uma tarefa
Servidor HTTP
   ↓ chama o código do banco
SQLite
   ↓ lê ou grava
data/foco-ai.db

Nesta aula, construiremos apenas src/database.js → SQLite → data/foco-ai.db. A ligação do servidor ao banco virá depois.

Arquivos

ArquivoFunção
src/server.jsJá existe; responde /health.
src/database.jsSerá criado; define a tabela e consulta tarefas.
data/foco-ai.dbSerá criado automaticamente; contém os dados locais.
.gitignoreJá ignora *.db, então o banco local não vai para o GitHub.

Tabela tasks

ColunaExemploRegra
id1Identificador automático.
titleCriar a primeira tela do FocoAIObrigatório e único.
statuspendingAceita apenas pending ou done.
created_atData e horaPreenchido automaticamente.

Resultado observável

node src/database.js imprimirá uma tabela contendo uma tarefa persistida no arquivo data/foco-ai.db.

Fora de escopo

Interface visual, CRUD pelo navegador, IA e conexão entre server.js e o banco serão construídos em aulas posteriores.
