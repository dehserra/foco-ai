Crie o banco de tarefas com SQLite

Você criará um banco de dados local em arquivo, definirá a tabela tasks e consultará uma tarefa real pelo terminal. Não instalaremos pacotes: o Node 24 já inclui node:sqlite.

Vitória desta aula: o comando node src/database.js imprimirá uma tabela com uma tarefa armazenada em data/foco-ai.db.

Leia primeiro: mapa conceitual da Aula 3.

Modelo mental mínimo

TermoFunção no FocoAI
Banco SQLiteUm arquivo local que guarda dados estruturados.
TabelaUma coleção de registros do mesmo tipo: tasks.
ColunaUma propriedade de cada tarefa: título, status ou data.
Linha / registroUma tarefa específica armazenada na tabela.
SchemaA definição da estrutura e das regras da tabela.

Faça agora

  1. Confira o ponto de partida. No terminal da pasta minicurso-dev, execute:
    git status
node --version
    Você precisa estar na branch main, com o estado limpo, e usar Node 24 ou mais recente. Se houver somente atualizações revisadas de materiais do curso, agrupe-as em um commit de documentação antes de continuar: git add -A, git status, git commit -m "docs: atualizar materiais da aula", git push.
  2. Crie o arquivo do banco. No Explorer do VS Code, clique com o botão direito em src → New File → escreva database.js. Cole e salve:
    const { mkdirSync } = require("node:fs");
const { DatabaseSync } = require("node:sqlite");

mkdirSync("data", { recursive: true });

const database = new DatabaseSync("data/foco-ai.db");

database.exec(`
  CREATE TABLE IF NOT EXISTS tasks (
    id INTEGER PRIMARY KEY,
    title TEXT NOT NULL UNIQUE,
    status TEXT NOT NULL DEFAULT 'pending'
      CHECK (status IN ('pending', 'done')),
    created_at TEXT NOT NULL DEFAULT CURRENT_TIMESTAMP
  );
`);

const addTask = database.prepare(`
  INSERT OR IGNORE INTO tasks (title, status)
  VALUES (?, ?)
`);

addTask.run("Criar a primeira tela do FocoAI", "pending");

const tasks = database.prepare(`
  SELECT id, title, status, created_at
  FROM tasks
  ORDER BY id
`).all();

console.table(tasks);
database.close();
  3. Execute o arquivo. No terminal, execute:
    node src/database.js
    Resultado esperado: uma tabela contendo uma linha com o título Criar a primeira tela do FocoAI e status pending. O arquivo data/foco-ai.db será criado automaticamente. Ele não aparecerá no git status, pois *.db já está no .gitignore.
  4. Leia o schema. No código, localize CREATE TABLE IF NOT EXISTS tasks. Ele só cria a tabela se ela ainda não existe. Confira as regras: title é obrigatório e único; status começa como pending e só aceita pending ou done; created_at recebe a data automaticamente.
  5. Teste a persistência. Execute o mesmo comando uma segunda vez:
    node src/database.js
    O resultado deve continuar com uma única tarefa, não duas. INSERT OR IGNORE ignora a tentativa de inserir um título que já existe. Isso prova que a segunda execução leu o mesmo arquivo de banco.
  6. Registre a entrega. Execute:
    git status
git add -A
git status
git commit -m "feat: adicionar banco SQLite de tarefas"
git push
git status
    Resultado final: estado limpo e branch atualizada no GitHub. O código src/database.js entra no commit; o arquivo local data/foco-ai.db não entra.

O que cada bloco de código fez

BlocoFunção
mkdirSyncCria a pasta data quando ela ainda não existe.
new DatabaseSyncAbre ou cria o arquivo SQLite.
database.execExecuta o SQL que define a tabela.
database.preparePrepara uma consulta SQL com valores seguros.
console.tableMostra o resultado da consulta de forma legível no terminal.

Se algo der errado

Cannot find module 'node:sqlite': rode node --version. Esta aula exige Node 24 ou mais recente.

near "pending": syntax error: copie o código novamente; aspas, vírgulas e parênteses do schema são significativos.

Aparecem duas tarefas iguais: apague somente o arquivo local data/foco-ai.db, execute o script uma vez e confira o SQL INSERT OR IGNORE. Não execute git add -A antes de verificar que o banco continua ignorado.
