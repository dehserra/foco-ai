# Mission: construir e publicar o FocoAI

## Why
André quer aprender o ciclo completo de desenvolvimento entregando um sistema pequeno e real, não apenas comandos isolados. O resultado será uma aplicação web que guarda tarefas em SQLite e usa IA para transformá-las em próximos passos práticos.

## Success looks like
- Criar, versionar e publicar o FocoAI em um repositório próprio no GitHub.
- Trabalhar com branches, commits, pull requests, merge, rebase, conflitos e worktrees de forma segura.
- Usar o VS Code para editar, depurar, testar, revisar mudanças e operar Git.
- Modelar e consultar dados em SQLite e integrar uma chamada de IA sem expor a chave.
- Fazer uma entrega versionada, com testes, documentação e uma demonstração local.

## Constraints
- Aprender construindo um projeto pequeno, em passos curtos e com uma evidência verificável por etapa.
- Usar Node.js, JavaScript, SQLite integrado ao Node e a API da OpenAI em uma etapa posterior e opcional.
- Ambiente atual confirmado no terminal do usuário: Windows 11, Git 2.53, Node 24.21.0, npm 11.19 e VS Code 1.139.

## Out of scope
- Produção em larga escala, autenticação de usuários, infraestrutura em nuvem e arquitetura de microserviços.
